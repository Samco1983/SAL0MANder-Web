## 3. Jigsaw Puzzle Suitability Validation

Every image in this library was designed and verified against the educational jigsaw puzzle specifications:

1. **Edge-to-Edge Visual Richness:** No large empty flat skies, blank walls, or featureless voids. Every piece in a 4, 6, 9, 12, or 16-piece grid contains identifiable textures and distinct color landmarks.
2. **High Chromatic & Geometric Separation:** Clear hue shifts between adjacent areas (e.g., turquoise waters against orange corals, purple nebulae against golden planet rings, emerald pines against blue alpine waters) to allow students to visually deduce piece locations.
3. **Safe Central Subject Area:** Key focal elements (turtles, airships, castles, trains, dinosaurs, macaws, robots) are kept within the inner 85–90% bounds, avoiding essential elements being bisected by the outer border.
4. **Clean Seamless Artwork:** Zero watermarks, logos, typography, signatures, UI elements, or pre-drawn puzzle cutouts.
5. **Multi-Aspect Ratio Support:**
   - **Square (1:1):** Tailored for standard demo activity square boards.
   - **Landscape (4:3):** Matches Unity's native `3.84 × 2.88` board format.
   - **Portrait (3:4):** Matches Unity's native `2.88 × 3.84` portrait board format.
   - **Custom Wide (3:2 & 16:9) & Custom Tall (2:3):** Built for custom ratio imports in Teacher Studio.

## 4. Downstream Asset Derivative Pipeline

> [!NOTE]
> Source originals are preserved in `/Users/samuel_saldivar/Desktop/SAL0MANder-Web/assets/image_library/`. They should **not** be placed uncompressed into the main Unity WebGL build directly.

When generating production derivatives:
- **`display_1024`:** Resize source image to max dimension `1024px` at WebP / JPEG quality 85 (~150–250 KB) for fast classroom WebGL download.
- **`display_512` (Thumbnails / Previews):** Resize to max dimension `512px` (~40–80 KB) for activity selection cards and companion previews.
- **Checksums:** Compute SHA-256 for each generated derivative for immutable `AssetVariant` caching per `ASSET_PIPELINE.md`.
