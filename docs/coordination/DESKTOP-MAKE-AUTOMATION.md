# Desktop + Make Automation

Purpose: make Mission Control easier to operate without turning Make into the
local executor.

## Split Of Duties

| Layer | Owns | Must Not Own |
| --- | --- | --- |
| Desktop launchd | waking local scripts on Samuel's Mac | product decisions |
| Terminal scripts | local checks, worker loop, logs, commits | secrets or arbitrary remote commands |
| Make Cloud | buttons, webhooks, notifications, Google Docs mirror | local code execution |
| GitHub | durable work queue and evidence ledger | hidden state |

## Desktop Commands

All commands run from `/Users/samuel_saldivar/Desktop/SAL0MANder-Web`.

```bash
npm run mission:desktop:status
npm run mission:desktop:install
npm run mission:desktop:uninstall
npm run mission:desktop:run-once
npm run mission:desktop:pause -- "reason"
npm run mission:desktop:resume
npm run mission:desktop:logs
```

`status` and `logs` are read-only. `install`, `uninstall`, `pause`, and
`resume` intentionally change local Mac state.

## Make Payload Commands

These generate JSON bodies Make can use for manual buttons or webhooks. They do
not call Make and do not mutate live scenarios.

```bash
npm run make:payload:nudge
npm run make:payload:done
npm run make:payload:blockers
npm run make:payload:control-room
```

Output:

```text
docs/coordination/ops/MAKE-PAYLOAD-LATEST.json
```

## Button Contracts

### NUDGE AGENTS

Goal: update one GitHub dashboard comment asking each lane for a structured
state with evidence.

Generated by:

```bash
npm run make:payload:nudge
```

### DONE - NEED NEW TASK

Goal: find the next unclaimed `[WEB]` issue and turn it into the current local
task.

Generated by:

```bash
npm run make:payload:done
```

### BLOCKER STATUS

Goal: report the published blockers and whether Samuel is still being forced to
relay between agents.

Generated by:

```bash
npm run make:payload:blockers
```

### OPEN CONTROL ROOM

Goal: show the one-screen local status surface.

Generated by:

```bash
npm run make:payload:control-room
```

## Installation Rule

Written automation is not live automation. The launchd plist exists in the
repo, but it is not installed until `mission:desktop:install` is run.

## Safety Rule

Make may request or signal. Local scripts decide whether a request is safe.
No Make payload should contain shell chosen by Make or by an agent.
