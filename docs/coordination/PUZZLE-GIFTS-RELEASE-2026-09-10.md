# Puzzle Gifts and matched game release

Puzzle Gifts adds a separate no-account composer and recipient entry. Senders choose a built-in picture and Learning Puzzle, Mystery Reveal, Classic Jigsaw or Slide & Solve. Learning/Mystery use nine fixed favorite-question stems with short typed answers; Classic/Slide stay picture-only. An occasion, box/envelope and celebration decorate opening and actual game completion. Copy, email draft and device sharing retain the complete link; none claims that a message was delivered.

**Open a gift** recovers a complete link, fragment or full backup code locally. It rejects malformed/unsupported data, discards a pasted URL's origin, and waits for deliberate opening before launching Unity. It requires a reachable compatible website; it is not an offline or domain-outage solution.

The matched player repairs native Gift replay/result clearing and Mystery replay/resize framing. Ordinary Matching and current-picture Slide remain separate from Gift mode support. Matching is not a Gift option. The existing forest pictures, visible piece recovery, canonical public demo links, dark theme and phone navigation are included through this branch's ancestry.
